# Note Tidy 中文说明

> English documentation: [README.md](README.md)

## 1. 概述

Note Tidy 是一个 Obsidian 桌面插件，用于整理仓库中的图片与笔记排版。插件提供以下能力：

- 把外部路径图片导入仓库，并改为内部链接；
- 转换图片格式，合并重复图片，清理未引用的图片；
- 重命名乱码图片，设置图片大小，整理图片位置；
- 修复笔记排版：行首缩进、标记、聊天记录、Bangumi 讨论、公式、空格、标签与内容块；
- 接管粘贴图片，并按设置自动处理粘贴内容；
- 把图片以文件形式复制到系统剪贴板。

命令面板与右键菜单提供相同入口，可对单篇笔记或整个仓库执行。运行环境为桌面端（`isDesktopOnly: true`）。

## 2. 安装

### 2.1 从社区插件市场安装

在 Obsidian「设置 → 第三方插件 → 浏览」中搜索 Note Tidy，安装并启用。

### 2.2 手动安装

1. 从 [Releases](https://github.com/Kflho/obsidian-note-tidy/releases) 下载 `main.js`、`manifest.json` 与 `styles.css`；
2. 将上述文件放入 `<仓库>/.obsidian/plugins/note-tidy/`；
3. 重启 Obsidian，在「设置 → 第三方插件」中启用 Note Tidy。

## 3. 功能

### 3.1 导入外部图片

笔记中以绝对路径引用的图片（如 `file:///<盘符>:/Images/photo.png` 或 `C:\Users\<用户名>\pic.jpg`）可以导入仓库，并转换为 `![[图片名]]` 形式。

导入时按设置处理：

- 图片复制到附件文件夹，位置遵循 Obsidian 的附件设置；
- 开启「导入的图片转成目标格式」后，图片在写入仓库前转换为目标格式（默认 WebP）；
- 无法解码的图片（如 HEIC、TIFF）保持原格式写入；
- 转换结果即使大于原文件也会保留，以保证仓库格式统一。

命令：`导入当前笔记的外部图片`、`导入整个仓库的外部图片`。

### 3.2 图片格式转换

命令：`转换当前笔记的图片格式`、`转换整个仓库的图片格式`。目标格式在「设置 → 图片 → 格式转换」中选择：WebP、JPEG、PNG、PNG（pngquant 压缩）。

- 动图与已是目标格式的图片不转换；
- 目标格式为 PNG（pngquant 压缩）时，插件调用系统中安装的 pngquant；未找到时保留原格式并提示；
- 转换会重写图片文件并修改扩展名，执行前弹出确认框；
- 转换后的链接由 Obsidian 原生重命名接口更新，wikilink、Markdown 链接与 canvas 一并更新。

### 3.3 重命名乱码图片

插件可以把文件名混乱的图片（如 `Q)\TN\Q)TNF]S%MRO@AI1(F[I]OYC.gif`、`%01...png`）重命名为统一格式。重命名同时修改磁盘文件名与全部引用链接，包括 Markdown 链接、双链与 canvas。

默认命名预设为 `Pasted image {YYYY}{MM}{DD}{HH}{mm}{ss}`，可在设置中使用 `{YYYY}`、`{MM}`、`{DD}`、`{HH}`、`{mm}`、`{ss}` 占位符自定义。

命令：`重命名当前笔记中的乱码图片`、`重命名整个仓库中的乱码图片`、`按预设格式重命名整个仓库的图片`、`强制按预设格式重命名整个仓库的图片`。

### 3.4 聊天记录排版

插件可以把 QQ、微信等聊天记录整理为统一格式：

- 用户名、日期、时间可分别显示或隐藏；
- 正文缩进、相邻消息排序、消息间空行、@ 提及、图片位置均可配置；
- 同一用户连续发送多条消息时合并为一条，只保留第一条的用户名与时间；
- 粘贴时自动排版本次粘贴的内容（可在设置中关闭），也可通过命令处理整篇笔记或整个仓库。

两种粘贴方式：

- **Ctrl+V**：粘贴为纯内容，不带用户名、日期、时间，消息之间不留空行，图文消息保持原顺序；正文缩进、按时间排序与去掉 @ 提及仍按设置执行。
- **右键「粘贴为聊天记录」**：按完整聊天记录格式粘贴，头部按设置显示用户名、日期与时间。

粘贴排版只处理本次粘贴的文本范围，不修改笔记其他部分。

### 3.5 Bangumi 讨论导入

粘贴从 bgm.tv 复制的讨论页，或执行 `从 bgm.tv 网页导入讨论到当前笔记` 并填入 `group/topic/<id>` 地址，插件会把楼层转换为笔记正文：

- 删除楼层头部、折叠标记、回复控件与页脚；
- 楼层转换为「用户名（签名）」加正文的形式；
- 引用的回复转换为引用块；
- 网页导入可沿 `?page=` 参数合并全部分页；
- 楼层与时间、签名、表情、图片处理方式可在设置中配置。

### 3.6 图片大小

插件可为图片添加 `|宽度` 或 `|宽度x高度` 尺寸标记：

- 默认宽度与高度可配置；高度留空时按宽度等比缩放；
- 开启「覆盖已有尺寸」时，已有尺寸也会改为默认值；
- 粘贴图片时可按默认尺寸自动套用，撤销一次即可回退；
- 执行前弹窗显示影响范围、修改数量与前后示例。

命令：`设置当前笔记的图片大小`、`设置整个仓库的图片大小`、`快速设置当前笔记的图片大小`。

### 3.7 整理图片位置

插件可以把某篇笔记引用的图片移入该笔记的附件文件夹：

- 仅该笔记使用该图片时，执行移动；
- 其他笔记或 canvas 仍引用该图片时，执行复制，原文件保留；
- 任一文档无法读取时，本次整理全部改为复制，并在结果中说明原因。

命令：`整理当前笔记的图片位置`、`整理整个仓库的图片位置`。

### 3.8 整理图片

「整理图片」一次完成格式转换、合并重复图片与清理未引用图片，执行顺序固定：

1. 改写引用；
2. 合并内容相同的重复图片；
3. 转换图片格式；
4. 清理未引用的图片。

插件只合并同一文件夹内内容完全相同的重复图片；不同文件夹中的相同图片不合并，以免破坏「整理图片位置」为各笔记建立的独立副本。合并时保留被引用次数最多的图片，其余链接改为指向保留的图片，多余文件移入回收站。

未引用图片的清理只处理图片文件，PDF、音频等其他附件不在处理范围内。三件事分别受「整理时转换图片格式」「整理时清理未引用的图片」控制。

入口：命令 `整理图片`、文件与文件夹右键的「图片功能」二级栏、左侧栏图标。命令与右键菜单先弹确认框；左侧栏图标直接执行。

### 3.9 粘贴处理

开启「粘贴图片时逐张保存」后，插件接管剪贴板图片的保存：

- 一次粘贴多张图片时逐张保存，避免并发写入导致文件名冲突与图片丢失；
- 图片按命名预设命名，并按设置转换格式；
- 保存后可按开关自动导入外部图片、自动排版聊天记录、自动套用默认尺寸；
- 粘贴期间再次粘贴会被拒绝，并提示等待复制完成。

三个自动处理开关分别控制导入外部图片、排版聊天记录与套用默认尺寸，只作用于本次粘贴的范围。

### 3.10 复制图片

「复制图片」把图片以文件形式写入系统剪贴板：

- Windows 下同时写入文件列表与位图，资源管理器可粘贴出文件，聊天软件可粘贴出图片；
- macOS 下写入文件列表；
- 选区同时包含文字与图片时，写入 HTML、纯文本与文件列表，供 QQ、微信等支持富文本的程序粘贴图文混排；该能力仅限 Windows。

命令：`复制图片到剪贴板`。可在设置中开启 Ctrl+C 优先复制图片。

### 3.11 文本排版

文本排版包含以下规则：

- 空格：中英文之间、中文与数字之间、英文与数字之间、公式与文字之间、数字与单位之间、全角标点前后、括号内侧；
- 标点：全角与半角按语境统一；
- 公式：LaTeX 公式代码的空格、换行与续行缩进；
- 标签：标签移到内容块末尾、标签排序；
- 内容块：按首字母排序；
- 列表：列表序号从 1 开始；
- 标题：子标题比父标题低一级；
- 智能公式：正文中的数学符号识别并包裹为 `$…$`。

命令：`修复当前笔记的排版`、`修复整个仓库的排版`。

### 3.12 排版选中内容

`排版选中内容` 只处理选中的文本，不修改笔记其他部分。插件会先导入选中文本中的外部路径图片，再执行排版规则。

结果写回编辑器，不写盘；撤销一次即可回退。

### 3.13 右键菜单管理

插件在图片菜单、笔记菜单与文件菜单中加入条目。可在「设置 → 菜单与交互 → 右键菜单项」中逐项启用或隐藏，也可执行 `管理右键菜单` 打开管理面板：

- 按图片、笔记、文件夹列出最近一次检测到的菜单项；
- 开关打开时显示，关闭时隐藏；
- 本插件自己的项由各自开关控制；
- 可一次恢复全部隐藏项。

### 3.14 状态栏

状态栏有两个独立区域：

- 批量任务执行时显示进度与结果，结果在 5 秒后清空；
- 开启「状态栏显示选中图片数量」后，显示当前选区中的图片数量。

## 4. 设置

设置分为三个页面：

| 页面 | 内容 |
| --- | --- |
| 图片 | 附件与命名、格式转换、粘贴、图片大小、一键整理 |
| 文本排版 | 行首与标记、聊天记录格式、提取为纯内容的格式、Bangumi 讨论、公式、文字间距、标点与符号、标签与内容块 |
| 菜单与交互 | 右键菜单项、复制与状态栏 |

常用设置：

- **附件存储位置**：跟随系统设置、仓库根目录、当前文件所在文件夹、子文件夹或指定的附件文件夹；
- **图片命名预设**：图片重命名时使用的格式；
- **图片格式转换的目标格式**：两条转换命令与「整理图片」共用；
- **转换质量**：1–100，默认 75；
- **pngquant 可执行文件路径**：留空时按系统 PATH 与常见安装位置查找；
- **导入的图片转成目标格式**：导入时转换格式，默认开启；
- **整理时转换图片格式**：整理图片时转换格式，默认开启；
- **粘贴图片时逐张保存**：接管粘贴图片，默认开启；
- **自动导入外部图片**、**自动排版聊天记录**、**自动套用默认尺寸**：粘贴后的自动处理，默认开启；
- **默认宽度**、**默认高度**、**覆盖已有尺寸**：图片大小的默认值；
- **左侧栏图标**、**整理时清理未引用的图片**：整理图片的入口与清理范围；
- **行首缩进修复**、**整理列表序号**、**整理标题级别**：基础排版；
- **显示用户名**、**显示日期**、**显示时间**、**同一用户连续消息合并**、**消息之间插入空行**、**图文消息中图片的位置**：聊天记录格式；
- **正文缩进**、**相邻消息按时间排序**、**去掉 @ 提及**：纯内容的格式；
- **显示楼层号**、**显示楼层时间**、**保留签名**、**去掉贴贴与页面控件**、**去掉表情**、**用户名带主页链接**、**网页导入时的图片**、**网页导入时的标题**：Bangumi 讨论；
- **数学符号自动转为公式**、**公式排版**：公式；
- **中文与英文之间**、**中文与数字之间**、**英文与数字之间**、**公式与文字之间**、**标题标记与标题内容之间**：文字间距；
- **全角标点前后不留空格**、**半角标点前不留空格、后空一格**、**括号内侧不留空格**、**数字与单位之间空一格**、**标点全半角按语境**、**符号间距规则**：标点与符号；
- **标签排版**、**标签排序**、**内容块排序**：标签与内容块；
- **Ctrl+C 优先复制图片**、**状态栏显示选中图片数量**：复制与状态栏。

## 5. 支持的图片格式

支持的图片格式包括 PNG、JPEG、GIF、BMP、WebP、HEIC、AVIF。格式转换的目标格式支持 WebP、JPEG、PNG 与 PNG（pngquant 压缩）。GIF 动图不参与格式转换。

## 6. 注意事项

- 大量操作前请备份仓库；
- 重命名图片会修改磁盘文件名。重命名后在编辑器中按 Ctrl+Z 仅撤销文本链接，不会恢复文件名，可能导致图片链接失效；
- 格式转换后，原有格式的图片会在整理或转换命令执行时被替换；
- 清理未引用的图片前，应确认笔记与 canvas 均已完整扫描；
- 合并与清理都会把文件移入回收站，可在回收站中恢复。

## 7. 隐私

插件不联网，不包含遥测，不上传任何内容。所有图片与文本处理均在本机完成。
