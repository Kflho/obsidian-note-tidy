# Note Tidy 中文说明

> English documentation: [README.md](README.md)

## 1. 概述

Note Tidy 是一款 Obsidian 桌面端插件，用于整理仓库中的图片与正文排版。插件提供以下能力：将外部绝对路径图片导入仓库并转换为内部链接、重命名乱码图片、调整图片大小与位置、合并重复图片、清理未被引用的图片，以及排版正文中的中英文空格、标点、公式、标签、板块、列表与标题。

上述功能均提供右键菜单与命令面板入口，可对单篇笔记或整个仓库执行。

## 2. 安装

### 2.1 从社区插件市场安装

在 Obsidian「设置 → 第三方插件 → 浏览」中搜索 Note Tidy，安装并启用。

### 2.2 手动安装

1. 从 [Releases](https://github.com/Kflho/obsidian-note-tidy/releases) 下载 `main.js`、`manifest.json` 与 `styles.css`；
2. 将上述文件放入 `<仓库>/.obsidian/plugins/note-tidy/`；
3. 重启 Obsidian，在「设置 → 第三方插件」中启用 Note Tidy。

## 3. 功能

### 3.1 外部图片导入

笔记中以绝对路径引用的图片（例如 `file:///D:/Images/photo.png` 或 `C:\Users\<用户名>\pic.jpg`）可导入仓库，并转换为 `![[图片名]]` 形式。

导入时按设置处理：

- 图片复制到附件文件夹，并遵循附件文件夹配置；
- 开启「导入的图片转成目标格式」后，图片在写入仓库前转换为目标格式（默认 WebP）。转换使用浏览器内置的 Canvas 编码器，不依赖其他插件；
- 无法解码的图片（例如 HEIC、TIFF）保持原格式写入，不因转换失败而丢失；
- 转换结果即使大于原文件也会保留，以保证仓库内格式统一。

### 3.2 乱码图片重命名

插件可将文件名混乱的图片（例如 `Q)\TN\Q)TNF]S%MRO@AI1(F[I]OYC.gif`、`%01...png`）重命名为统一格式。重命名同时修改磁盘文件名与全部引用链接，包括 Markdown 链接、双链与 Canvas。

默认命名预设为 `Pasted image {YYYY}{MM}{DD}{HH}{mm}{ss}`，可在设置中使用 `{YYYY}`、`{MM}`、`{DD}`、`{HH}`、`{mm}`、`{ss}` 占位符自定义。

### 3.3 聊天记录排版

插件可将 QQ、微信等聊天记录整理为统一格式：

- 用户名、日期、时间、楼层号与楼层时间可分别显示或隐藏；
- 正文缩进、相邻消息排序、消息间空行、@提及、签名、表情与页面控件均可配置；
- 同一个人连发多条时合并成一条，只留第一条的用户名与时间；
- 图片在图文消息中的位置可配置；
- 聊天记录排版在粘贴时自动执行（可在设置中关闭），也可通过命令对整个仓库执行。

两种粘贴方式：

- **Ctrl+V**：粘贴为纯内容 —— 不带用户名、日期、时间，消息之间不留空行，图文消息保持原顺序；正文缩进、按时间排序、去掉 @ 仍按设置。
- **右键「粘贴为聊天记录」**：按完整聊天记录格式粘贴，头部按设置显示用户名、日期与时间。

粘贴排版仅处理本次粘贴的文本范围，不修改笔记其他部分。

### 3.4 Bangumi 讨论导入

粘贴从 bgm.tv 复制的讨论页，或执行「从 bgm.tv 网页导入讨论到当前笔记」并填入 `group/topic/<id>` 地址，插件将楼层转换为笔记正文：

- 去除楼层头部、折叠标记、回复控件与页脚；
- 楼层转换为「用户名（签名）」加正文的形式；
- 引用的回复转换为引用块；
- 网页导入可沿 `?page=` 参数合并全部分页；
- 楼层与时间、签名、表情、图片处理方式可在设置中配置。

### 3.5 图片大小

插件可为图片添加 `|宽度` 或 `|宽度x高度` 尺寸标记：

- 默认宽度与高度可配置；高度留空时按宽度等比缩放；
- 「覆盖已有尺寸」开启时，已带尺寸的图片也会改为默认值；
- 粘贴图片时可按默认尺寸自动套用，撤销一次即可回退。

### 3.6 整理图片

「整理图片」为一次任务，包含三个步骤，执行顺序固定：

1. 重写链接；
2. 合并重复副本；
3. 转换格式；
4. 清理未被引用的图片。

插件仅合并同一文件夹内内容完全相同的副本；不同文件夹中的相同图片不合并，以避免破坏「整理笔记图片位置」为各笔记建立的独立副本。合并时保留被引用次数最多的副本，其余副本的链接改为指向保留副本，多余文件移入回收站。

未被引用的图片清理仅处理图片文件，PDF、音频等其他附件不在处理范围。

### 3.7 整理笔记图片位置

插件可将某篇笔记引用的图片移入该笔记的附件文件夹：

- 仅该笔记使用该图片时，执行移动；
- 其他笔记或 Canvas 仍引用该图片时，执行复制，原文件保留；
- 若任一文档无法读取，本次整理全部改为复制，并在结果中说明原因。

### 3.8 粘贴接管与自动修复

开启「接管图片粘贴」后，插件接管剪贴板图片的保存：

- 一次粘贴多张图片时逐张保存，避免并发写入导致文件名冲突与图片丢失；
- 图片按命名预设命名，并按设置转换格式；
- 保存后可自动收图、自动排版聊天记录、自动套用默认尺寸；
- 粘贴期间再次粘贴会被拒绝，并提示等待复制完成。

### 3.9 复制图片

「复制图片」将图片以文件形式写入系统剪贴板：

- Windows 下同时写入文件列表与位图，资源管理器可粘贴出文件，聊天软件可粘贴出图片；
- macOS 下写入文件列表；
- 复制选中内容同时包含文字与图片时，写入 HTML、纯文本与文件列表，供 QQ、微信等支持富文本的程序粘贴图文混排；该能力仅限 Windows。

### 3.10 文本排版

文本排版包含以下规则：

- 空格：中英文之间、中文与数字之间、英文与数字之间、公式与文字之间、数字与单位之间、全角标点两侧、括号两侧；
- 标点：全角与半角按语境统一；
- 公式：LaTeX 公式代码的空格、换行与续行缩进；
- 标签：标签归位到块末尾、表格内标签、标签排序；
- 板块：按标题划分内容板块并排序；
- 列表：列表序号从 1 开始；
- 标题：子标题比父标题低一级；
- 智能公式：正文中的数学符号识别并包裹为 `$…$`。

### 3.11 选区排版

「排版选中内容」仅处理选中的文本，不修改笔记其他部分。插件会先导入选中文本中的外部路径图片，再执行排版规则。

### 3.12 右键菜单管理

插件在图片菜单、笔记菜单与文件菜单中加入条目。可在「设置 → 菜单与交互」中逐项启用或隐藏，也可整体隐藏某个菜单项。

## 4. 设置

设置分为三个页面：

| 页面 | 内容 |
| --- | --- |
| 图片 | 附件存储位置与名称、图片命名预设、格式转换、粘贴行为、图片大小、一键整理 |
| 文本排版 | 聊天记录、Bangumi 讨论、列表序号、标题级别、标签、板块、公式、空格规则 |
| 菜单与交互 | 右键菜单项、文件菜单二级栏、隐藏菜单项、Ctrl+C 接管、状态栏图片数量 |

## 5. 支持的图片格式

支持的图片格式包括 PNG、JPEG、GIF、BMP、WebP、HEIC、AVIF。格式转换的目标格式支持 WebP、JPEG、PNG 与 PNG（pngquant 压缩）。GIF 动图不参与格式转换。

## 6. 注意事项

- 大量操作前请备份仓库；
- 重命名图片会修改磁盘文件。重命名后在编辑器中按 Ctrl+Z 仅撤销文本链接，不会恢复文件名，可能导致图片链接失效；
- 格式转换的目标格式统一后，原有格式的图片会在整理或转换命令执行时被替换；
- 清理未被引用的图片前应确认笔记与 Canvas 均已完整扫描。

## 7. 隐私

插件不联网，不包含遥测，不上传任何内容。所有图片与文本处理均在本机完成。
