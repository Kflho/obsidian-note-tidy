# Note Tidy 中文说明

> English documentation: [README.md](README.md)

**Note Tidy（笔记整理）**：把仓库收拾干净 —— 外部绝对路径图片搬进仓库并转成 `![[...]]` 双链、乱码图片重命名、图片大小与位置整理，以及正文排版：中英文 / 数字 / 公式 / 标点之间的空格、标点全半角、LaTeX 公式代码、标签归位与排序、板块排序、聊天记录重排、智能公式。单篇或整个仓库，右键菜单与命令面板都能用。

> v1.3.0 起由 **Absolute Image Transfer**（id `absolute-image-transfer`）改名而来。升级做法见上面的 [Renaming](README.md#renaming)：把 `.obsidian/plugins/absolute-image-transfer/` 文件夹改名成 `note-tidy`，`data.json` 一起带过去即可，设置不会丢。

## 功能

### 1. 外部图片转入仓库

把 `file:///D:\图片\photo.png` 或 `C:\Users\...\pic.jpg` 这类绝对路径图片复制到仓库的附件目录，并将链接替换为 `![[Pasted image 20260420123045.png]]`。图片存放位置遵循你的 Obsidian 附件设置。

**格式转换（自带编码器，不依赖别的插件）**：开着 **设置 → 图片导入 → 「导入的图片转成目标格式」**（默认开）时，每张导入的图片都会**先转换、再落盘**：转好之后才按目标格式（`png` → `webp`）写进附件夹，链接直接写成新文件名，仓库里不会出现谁也指不到的中间 png。转码用的是**浏览器自带的 canvas 编码器**（`canvas.toBlob`），所以不需要装任何别的插件。

另外还有两条命令 **把整个仓库的图片转换为指定格式** 与 **把当前笔记的图片转换为指定格式**（目标格式在 **设置 → 图片导入 → 「转换图片格式」的目标格式**，默认 webp；质量在 **转换质量**，默认 75）：前者扫全库、后者只处理当前笔记里 `![[…]]` 嵌入的图片 —— **想先看效果就拿一篇笔记试**。动图 `gif`、已经是目标格式的、以及转完反而更大的图片一律按原样留着。改名走 Obsidian 自己的重命名，所以 wikilink、Markdown 链接、canvas 都会自动跟着更新。

**转格式不会让图片丢**：解不开的格式（HEIC / TIFF 这类 Chromium 原生不认的）、编出来不是目标格式的、比原来更大的，全都按原格式留着 —— 宁可少转一张，也不会写坏一个字节。**粘贴图片也由本插件接管**（见第 4 节）。

**整理图片（转换 + 合并 + 清理）** —— 一个任务、三个入口：命令 **整理图片（转换格式 + 合并重复副本 + 清理没人引用的附件）** 与文件 / 文件夹右键「图片功能」里那一项（都先弹确认框）；**左侧栏的「整理图片」图标**（默认开，**设置 → 图片整理 → 左侧栏放一个「整理图片」图标**）—— **一键整理**，不弹确认框。想替代 **Clear Unused Images** 那个按钮就用它：图标特意沿用了对方的 `image-file`，位置和样子都不变，只是干的事变成"转换 + 合并 + 清理"。

整理按固定顺序做三件事：**① 改写引用 → ② 删掉重复副本 → ③ 转换格式 → ④ 清理没人引用的图片**。① 把**逐字节完全相同**的图片只留一张 —— 只合并**同一个文件夹里**的重复（那是"同一张图粘了两次"的手滑）；**跨文件夹的同图不动**，那是「整理图片位置」特意给每篇笔记拷的副本。判定分两步：先按"目录 + 字节数"粗分组（不读盘），再逐字节比对（不用哈希，也就没有"碰撞把两张不同的图判成一张"的风险）；**留被引用最多的那张**，其余副本的链接改写到它（双链 / Markdown / canvas 都改），副本进回收站。③ 把还不是目标格式的图片转成目标格式（**设置 → 图片整理 → 整理时转换图片格式**，默认开；目标格式取上面那一项，默认 webp）—— 排在合并之后，马上要进回收站的副本就不必白转一趟；动图与已经是目标格式的按原样留着。④ 清一遍"没人引用的图片"（**设置 → 图片整理 → 整理时清理没人引用的附件**，默认开，**自己实现、不依赖 Clear Unused Images**）：扫描全库笔记与 canvas 里出现过的图片文件名，一张都没被提到的送进回收站；**只清图片**（pdf、音频等一个都不碰），删除走回收站可还原，命令面板里还有一条单独的 **清理没人引用的图片**（那一条会先让你确认）。

### 2. 乱码图片重命名为预设格式

识别文件名中带特殊字符（`\`、`%`、`[]`、`()` 等）、URL 编码残留、纯数字+点号等自动生成命名的图片，统一重命名为干净格式。物理文件与全库引用链接同步更新。

**默认格式：** `Pasted image {YYYY}{MM}{DD}{HH}{mm}{ss}`

可在设置中自定义占位符组合。

### 3. 修复 QQ/微信聊天记录排版

将导出的聊天文本从混乱的单行时间戳格式，转换为带缩进的清晰排版。严格幂等，重复执行不会产生多余空行。

排版样式可在设置中调整：

| 设置项 | 说明 |
|--------|------|
| 显示用户名 | 关闭后每条消息只保留日期与时间 |
| 显示日期 | 格式为 `{YYYY}/{MM}/{DD}` |
| 显示时间 | 格式为 `{HH}:{mm}:{ss}` |
| 正文缩进 | 制表符 (tab) / 2 个空格 / 4 个空格 / 不缩进 |
| 图文消息中图片的位置 | 图片在上方 / 图片在下方 / 保持原顺序 |
| 相邻消息按时间排序 | 默认开启。比较**相邻**消息的时间戳并按时间先后输出 —— 修正 QQ / 微信 把文字归成一组、图片统一附在末尾的粘贴顺序。只有两条消息之间除了空白什么都没有时才重排（你自己写在中间的内容绝不搬动），且一整段里每条消息的时间戳必须是同一种形态（全带日期或全不带）。关掉就完全按粘贴顺序，详见下文 |
| 去掉 @ 提及 | 默认关闭（它会删字）。删除消息正文里的 `@昵称`：`@` 必须在词首（`foo@bar.com` 不动），整行只有提及的连整行一起删掉，行内其余文字保留。只在排版聊天记录时生效 —— 已经不带头部时间戳的区域（头部全部关掉的那种）不会被改写，详见下文 |
| 消息之间插入空行 | 默认关闭，是**总开关**（与头部信息开不开无关）：关闭时相邻消息紧挨着，**源文里消息之间的空行也一并去掉**（QQ / 微信 复制出来的记录常在消息之间带空行，所以"关掉还是有空行"）；开启时恰好留一行。中间夹着你自己的正文时不算相邻消息，那一段空白不动 |
| 粘贴聊天记录时自动修复 | 默认开启。在编辑器里粘贴的内容被识别为聊天记录（两条以上「用户名 + 时间戳」的消息头部）时，**只把刚粘进来的那一段**修好：这段里的外部图片收进仓库 + 按当前设置修一遍排版。笔记其余部分一个字符都不动，插件也不写盘（改动走编辑器自己的保存路径，撤销一次即可回退） |
| 行首缩进修复 | 智能：列表子项保留，其余行首空格删掉（推荐）/ 严格：行首只留 tab，空格全删 / 关闭。开启时同时规范注释（引用）、列表、标题的标记空白 |
| 整理列表序号 | 默认开启。保证每个列表的首项编号是 1；首项已是 1 的列表（含 `1. 1. 1.`、`1. 5. 9.`）一律不动 |
| 整理标题级别 | 默认开启。保证子标题与父标题恰好差一级；首个标题的级别保持原样 |

以上默认值与原版排版结果一致，升级后不改变已有笔记，只有主动修改设置才会生效；会重排**新粘贴内容**的默认项有两个：「相邻消息按时间排序」（见下）—— 它只在粘进来的消息顺序本来就是乱的时候动手，而已排好版的笔记里没有时间戳可比较，所以永远不会被它改到；以及默认关闭的「消息之间插入空行」—— 它会把 QQ / 微信 粘贴里**消息之间**带的空行收掉。

你自己正文里的空行始终保留：排版只收掉"两条相邻聊天消息之间"的那种空行，而且只在「消息之间插入空行」关闭时。

**相邻消息会按时间顺序摆正。** QQ / 微信 复制选区时并不按你看到的顺序给你：文字消息被归成一组、图片统一附在末尾（或者反过来），于是「19:41:37 的文字 + 19:41:38 的两张截图」粘出来是图片在前 —— 排版照实还原，图片就跑到了**上一条**消息的文字上方。开着这个开关（默认开）时，排版会比较**相邻**消息的时间戳，按时间先后输出：

- 只重排**相邻**的消息 —— 两条之间除了空白什么都没有。你自己写在两条消息之间的内容（`06集` 这类标题、一个段落）绝不会被搬动，它前后的消息也各自留在原位；
- 一整段里每条消息都得有**同一种形态**的可比时间戳（全部带日期，或全部只有时间）才会重排。混着来、或时间戳读不出来，一律按"原样不动"处理；
- 关掉开关，粘贴时的顺序原样保留。

**正文的终点只认空行与下一条消息头部。** 一条消息的正文一直延伸到空行或下一条消息头部为止 —— 多行消息就是这么工作的。所以整篇排版有一个诚实的局限：你在某条消息下面紧接着写自己的东西（`06集` 这类小标题、临时笔记、自己插的截图），中间没有空行时，整篇排版没有依据把它和这条消息的正文分开，只能算作正文一起缩进；反过来，你自己那行带缩进（编辑器自动缩进给的 tab）、粘进来的正文顶格时也一样。这不是再加几条启发式规则能可靠解决的 —— 想精确控制就**选中要排的那一段，用「排版选中内容」**（见下），那里没有这个歧义。

**只排版选中的内容**（命令 **排版选中的内容**，笔记正文右键菜单里的 **排版选中内容（Note Tidy）**，默认开启）—— 只排版选中的那段文字，笔记其余部分**一个字符都不动**。步骤与「快速修复聊天记录」相同，只是范围限定在选区：

1. 选区里用绝对路径引用的图片（`file:///D:\…`、`C:\…`）复制进仓库，链接换成 `![[…]]`；
2. 只对这段文字跑排版规则。

结果用编辑器替换选区写回（<kbd>Ctrl</kbd>+<kbd>Z</kbd> 一次即可回退，也不写盘），没有选中内容时菜单项不会出现。典型用法：把聊天记录粘进来 → 选中它 → 执行这一条；它前后的内容一点都不会被碰到，也就不需要谁来猜"消息到哪儿结束"。缩进与接缝的处理与粘贴那条路完全一样（见下）：选区落在列表项 / 引用块里，整块就排在那一层；选区首尾原本有几个换行，排完还是几个。

**@ 提及可以去掉**（**设置 → 排版格式 → 聊天记录 → 去掉 @ 提及**，默认关闭 —— 它会删字）：群聊里每条回复都以 `@昵称` 开头，而记录进了仓库之后，这个昵称指向谁都没意义了。开关打开后：

| 排版前 | 排版后 |
|--------|--------|
| `@徐晃何许人也 这才叫邪恶反派` | `这才叫邪恶反派` |
| `你说的对 @张三 就是这样` | `你说的对 就是这样` |
| `@张三 @李四 大家好` | `大家好` |
| `＠张三 大家好`（全角 `＠`） | `大家好` |
| `发到 foo@bar.com 就行` | 不动（`@` 在单词中间，不算提及） |
| 整行只有 `@张三` | 整行删掉（不会留下只有缩进的空行） |

**快速修复聊天记录** —— 命令面板、右键菜单、粘贴三处都能进：把「转换本文件内的外部图片」与「修复本文件内的排版」合成一步。从 QQ / 微信 粘出来的聊天记录，正文里往往是 `file:///D:\…` 这样的外部图片、排版也乱，点一次就都干净了。

开着「粘贴聊天记录时自动修复」（默认开）时，粘贴进来的聊天记录会**当场修好 —— 而且只改你刚粘进来的那一段**。判定很窄：要有**两条以上**「用户名 + 时间戳」的消息头部才算（正文里提一句 `会议 14:30:25` 不会触发；只复制单条消息本来也不带头部）。

它怎么知道"哪一段是刚粘的"：粘贴事件本身只用来看**粘在哪儿**（那时内容还没进文档 —— 真正插入的是 CodeMirror 的处理器），编辑器一报告变化，"那个位置 → 光标处"就是这次粘贴的内容；把这一段读回来，用同一把尺子再判一次，然后在原地修好：这段里按绝对路径引用的图片收进仓库，排版规则只作用在这段上，结果写回编辑器。于是：

- **你自己写的行一个字符都不会被动**（也不需要谁去猜"消息到哪儿结束"—— 想手动做同样的事就用上面的「排版选中内容」）；
- **缩进跟随你粘贴的位置。** 排版只看得到粘进来的那一段文字，以前它从第 0 列开始排、第一行却留在光标那一列 —— 在列表项里按回车（编辑器已经自动缩进 2 格）再粘贴，整块就"挂"在半空中，一半在列表项里、一半顶格。现在整块（头部行与正文行都算）都落在**光标那一层的缩进**上（那一行的行首空白与 `>` 链）：**光标缩进多少，粘完就是多少**，块内部的高低关系（有头部时正文比头部深一格）原样保留。这一段原本那一层缩进会在排版前先剥掉、排完再把整块落到光标那一层，所以两层不会互相吃掉（两边都用 tab 时，在 1 层缩进处粘贴以前会只剩 1 层）。别的行一概不参考 —— 拿上下相邻行的缩进来否决光标（"上下都顶格，所以你也不许缩进"）试过又撤掉了：把光标放在哪一列是明确的意思；
- **接缝不动。** 聊天记录排版总会在结尾补一个换行，以前会让粘贴块与下文之间多出一个空行；现在这一段首尾的换行数会还原成粘贴前的样子，粘一次不会改变它周围的疏密；
- 插件**不写盘**：改动走编辑器自己的保存路径，<kbd>Ctrl</kbd>+<kbd>Z</kbd> 一次即可回退；
- 编辑器迟迟没有变化（这次粘贴被别的插件吞了、视图不是 Markdown 视图……）时，5 秒后把这笔等待丢掉 —— 宁可什么都不做，也绝不去动整篇。

不想让它自动改就在设置里关掉，命令与右键菜单项不受影响。

同一条命令还会顺手修掉**行首的坏缩进**——从 QQ/微信复制来的文本，行首常常是"空格 + Tab"（`" \t"`）或"Tab 带零散空格"（`"\t\t "`）。规则是**行首只留 tab**，其中 4 个空格算一个 tab：

| 修复前 | 修复后 | 规则 |
|--------|--------|------|
| `" \t消息"` | `"\t消息"` | 空格 + Tab → Tab |
| `"\t\t 消息"` | `"\t\t消息"` | Tab 前后的零散空格删掉 |
| `"    消息"` | `"\t消息"` | 4 个空格 = 1 个 tab（列数不变，渲染层级不变） |
| `"  消息"` | `"消息"` | 正文、图片前手滑多打的 1~3 个空格删掉 |
| `"  - 子项"` | 不动 | 后面跟列表符号，这是真的嵌套缩进 |
| 列表项下方、隔空行的 `"  段落"` | 不动 | 它是该列表项里的段落，缩进有语法含义 |

frontmatter 与代码块（``` / ~~~）内部的缩进属于语法或内容，一律不碰。

同一条命令还会规范**块级标记**的空白 —— 注释（引用）、列表、标题：

| 修复前 | 修复后 | 规则 |
|--------|--------|------|
| `" >引用内容"` | `"> 引用内容"` | 引用标记前手滑多打的 1~3 个空格删掉，`>` 与正文之间补一个空格 |
| `">>引用内容"` | `"> > 引用内容"` | 多级引用连写规范成 `> > ` |
| `">[!note] 标题"` | `"> [!note] 标题"` | callout 标记后补空格 |
| `"-    项目"` | `"- 项目"` | 列表符号后多于一个空格收成一个 |
| `"1)   项目"` | `"1) 项目"` | 有序列表同样处理 |
| `"##   标题"` | `"## 标题"` | 标题符号后多于一个空格收成一个 |
| `"#标签"` | 不动 | 井号后没有空格是标签不是标题，加空格反而会变成标题 |
| `">   - 子项"` | 不动 | 引用里的嵌套块，标记后的缩进有语法含义 |
| `"- 顶层"` 下方的 `"  > 引用"` | 不动 | 这条引用属于该列表项，缩进是语法 |

> 说明：关闭「显示用户名」后头部只剩时间戳，此时聊天记录上方紧邻的其他文字会被原样保留、不参与排版，以免误删内容。

### 4. 一键设置图片大小

把"查找替换正则"换成一条命令：设置里定好尺寸，右键笔记 / 文件夹或命令面板一键应用。

**改写效果：**

```
![[图片.png]]               →  ![[图片.png|100]]
![[图片.png|300]]           →  ![[图片.png|100]]
![[图片.png|300x200]]       →  ![[图片.png|100]]
![[图片.png#outline]]       →  ![[图片.png#outline|100]]
![](https://x.com/a.jpg)    →  ![100](https://x.com/a.jpg)
![[图片.png|一张说明文字]]   →  不动（别名是说明文字，不是尺寸）
![[笔记.md]]                →  不动（不是图片）
```

相比直接跑正则的好处：

- **只写真正变化的文件**：尺寸已经正确的笔记完全不碰，不会产生保存、同步、diff 噪音
- **扩展名不区分大小写**，覆盖 `png` `jpg` `jpeg` `gif` `bmp` `webp` `heic` `avif` `svg`
- **支持 `|300x200`、`#outline` 片段和 Markdown 图片**（这些用 `(\|\d+)?` 正则会静默漏掉）
- **不会吃掉图片说明文字**：别名不是纯数字时一律保留
- **先预览再动手**：弹窗实时显示"将修改 N 处"和前后对比，改数字即时刷新
- 宽度和高度**都留空 = 移除已有尺寸**

**粘贴图片由本插件接管**（**设置 → 图片导入 → 粘贴图片由本插件接管**，默认开启）：在编辑器里粘图片文件时，本插件自己把图片存进附件夹（**一张一张**，名字走本插件那套不撞名的规矩，顺手转成目标格式）并把 `![[链接]]` 写进正文 —— 剪贴板里同时有文字时，文字也一并写上（**文字在前、图片在后**）。一次粘多张不会漏。**所以建议把 Image Converter 的「Never process filenames」填 `*`**，让它的自动粘贴 / 拖放处理让开：它那边是并发跑的（一批图各算各的输出名，同一秒撞名后写的直接丢图），这也是本插件接管这件事的原因。关掉这一项就回到"别人家的粘贴"。

**粘贴时自动套尺寸**（**设置 → 图片大小 → 粘贴图片时自动套用默认尺寸**，默认开启）把同一套参数自动用在**刚粘进来的图片**上：本插件自己接管的粘贴、别的插件存下的截图、以及粘贴文本里带的图片链接都算。它只重写刚粘的那一段 —— 笔记其余部分一个字符不动、插件不写盘、<kbd>Ctrl</kbd>+<kbd>Z</kbd> 一次即可回退。**一次粘多张图**也没问题：本插件接管时是一张一张存、存完整批再写回；别人家的粘贴可能是分几次落进编辑器的，插件会在粘贴处多盯几秒（每次变化重新计时，总寿命 20 秒封顶），而不是只看第一张就收工；重复跑是幂等的，已经有尺寸的图片不会再动。已经带着尺寸的图片要不要改，照上面的「覆盖已有尺寸」开关走；宽度留空（那一档是"移除已有尺寸"）、尺寸填错时整步跳过。粘进来的是一段聊天记录时，尺寸与排版**共用同一次写回**，撤销一次两步一起回退。

### 5. 整理笔记图片位置

复制粘贴笔记后，`![[图.png]]` 这类短链接仍然指向**原文件夹**的图片，本笔记的 attachments 里其实没有这张图 —— 原图一旦被移动、改名或删除，笔记里的图片就没了。

「整理图片位置」会把这类图片**复制**一份到笔记自己的附件夹，并把链接改成指向本地副本：

| 情况 | 处理 |
|------|------|
| 图片在别处，本地附件夹没有 | 复制一份到本地，链接改指本地 |
| 本地已有**内容相同**的副本 | 只改链接，不重复复制 |
| 本地有**同名但内容不同**的文件 | 复制成 `名字 2.ext`，绝不覆盖 |
| 链接同名有歧义、无法确定指向哪张 | 跳过并在提示里说明原因 |
| 图片本来就在本地附件夹 | 完全不动 |

同名图片多的时候，插件会强制写完整路径（如 `![[folderB/attachments/图.png]]`），避免裸文件名指向另一张同名图。入口在右键 **图片功能 → 整理…图片位置**，命令面板也可用（当前笔记 / 整个仓库）。

### 6. 标签排版与内容板块排版

两个会重排正文的排版功能，默认都关闭，需要在设置里主动开启。

**标签排版** —— 一块内容里同时有正文和标签时，标签统一挪到块尾，与正文之间空一格：

| 排版前 | 排版后 |
|--------|--------|
| `"#数学 今天学了极限"` | `"今天学了极限 #数学"` |
| `"今天学了 #数学 极限"` | `"今天学了 极限 #数学"` |
| `"今天学了极限 #数学。"` | `"今天学了极限。 #数学"` |
| `"- #标签 列表项内容"` | `"- 列表项内容 #标签"` |
| `"> #标签 引用内容"` | `"> 引用内容 #标签"` |
| `"\| #标签 单元格 \| 另一格 \|"` | `"\| 单元格 #标签 \| 另一格 \|"` |
| 整行只有标签 | 不动（位置不变、不与上下正文行合并，只按需排序） |

**块**的边界：一个段落算一块（标签挪到段落最后一行），一行列表项、一行标题各自算一块，**整行只有标签时这一行自成一块**（标签既不会被抽走，也不会接收别处的标签，连着两行纯标签行也不会被并成一行），**表格按单元格算块，不是按行** —— 整行算一块会把标签挪到别的列去，表格就毁了。

段落里夹着一行纯标签时，段落就在那里断开，两边的标签各归各的：

| 排版前 | 排版后 |
|--------|--------|
| `"#标签"` + `"下一行文字"` | 不动（纯标签行不会被并进下一行） |
| `"第一行"` + `"#标签"` + `"第三行"` | 不动（纯标签行不会被抽走） |
| `"#甲 第一行"` + `"#乙"` + `"第三行"` | `"第一行 #甲"` + `"#乙"` + `"第三行"` |

**标签排序** —— 同一处出现的多个标签按首字母排（中文按拼音、数字按数值）：`"内容 #数学 #笔记"` → `"内容 #笔记 #数学"`。

不碰的地方：frontmatter、围栏代码块与缩进代码块、行内代码、`%%注释%%`、双链与 Markdown 链接（`[[笔记#标题]]`、`[文字](url#锚点)` 里的 `#` 不是标签）、`C#` 这种紧贴字符的井号、纯数字的 `#123`。不带行首竖线的非标准表格（`甲 | 乙 | #标签 丙`）也整行不动。

**内容板块排版** —— 按首字母给笔记里的块排序（中文按拼音、数字按数值）：

- 连续的列表项之间排序、连续的段落之间排序，**列表与段落不会互相穿插**
- 标题是分节锚点：排序只发生在这个标题与下一个标题之间，标题本身不动
- 表格、图片、分隔线、脚注、聊天记录都是锚点：原地不动，并把左右两边的排序范围切开 —— 复制来的聊天记录不会被排乱
- 有序列表排完会顺手把编号写顺（只在原本就是连续编号时才动，手写的 `1. 1. 1.` 保持原样）

相关设置项：

| 设置项 | 说明 |
|--------|------|
| 标签排版 | 默认关闭。开启后把行内 `#标签` 统一移到所在块的句尾，与正文之间空一格 |
| 标签排序 | 默认开启（仅当「标签排版」开启时可用）。关闭后标签归位但保持原有先后顺序 |
| 内容板块排版 | 默认关闭。开启后按首字母对笔记各块内容排序 |

### 7. 公式排版

把数学公式的 LaTeX 代码整理成"**代码里的空格 = 公式渲染出来的空格**"：`$$ … $$` 区块管换行与缩进，行内 `$…$` 只按同一套空格规则整理、**绝不换行**。行内公式的识别与 Obsidian 一致：`$` 内侧紧贴内容才算公式（`$ 5 与 $` 这种不会被误当公式）。

| 排版前 | 排版后 | 规则 |
|--------|--------|------|
| `$$\dot{x}=f(x, t)$$` | `$$\dot{x} = f(x, t)$$` | 运算、关系、逻辑符号左右各一个空格（规则 1） |
| `$$a&b&c$$` | `$$a & b & c$$` | `&`、`\\` 是排版符号，左右各一个空格 |
| `$$(-x)$$` | `$$(-x)$$` | 标正负的加减号与参数贴紧（规则 2） |
| `$$(x-x_e)$$` | `$$(x - x_e)$$` | 真正的减法照旧左右加空格 |
| `$$\begin{cases}-1 & x<0\\ 1 & x\ge0\end{cases}$$` | `-1` 保持贴紧 | 环境开头（`\begin{cases}`、`\begin{bmatrix}`）同样是"缺操作数"的位置；`&`、`\\` 之后也一样 |
| `$$x^-1$$` | `$$x^-1$$` | 紧跟在 `^` / `_` 后面的符号就是上标/下标本身，与内容贴紧 |
| `$$f'-g$$` | `$$f' - g$$` | 撇号不吃后面的符号：那个减号是真的减法，左右都要空格 |
| `$$a\pmod{n}$$` | `$$a \pmod{n}$$` | 自带花括号参数的关系符命令与参数贴紧 |
| `$$Λ或等价地A$$` | `$$Λ\text{或等价地}A$$` | 公式里直接写的中文包成 `\text{…}`（规范里就是这么写的：`\text{i 为奇数}`）；环境开头与第一个元素保持连写（`\begin{cases}\le 0`） |
| `$$a_ij$$` | 不动 | 多字符上下标**不**自动补花括号：`a_ij`（矩阵元素）、`A^TP`（Aᵀ·P）、`k_mx_m`（k_m·x_m）三种写法完全一样，猜错就改了公式的含义 |
| `$$\partial f$$` | `$$\partial{f}$$` | 修饰符与参数贴紧；花括号保证命令名不被吃掉（规则 6） |
| `$$\sin x$$` / `$$\sin 2x$$` | `$$\sin{x}$$` / `$$\sin2x$$` | 只在"连起来会出错"时加花括号（`\sinx` 非法、`\sin2x` 合法） |
| `$$A_{i}, \quadA_{j}$$` | `$$A_{i}, A_{j}$$` | 间距命令与后面字母粘连（`\quadA` 会被 LaTeX 当成未定义命令，公式直接报错）会拆开：前面已有逗号等分隔就删掉多余的间距，否则写成 `\quad{A}` |
| ``$$ x = 1 $$`` | ``$$x = 1$$`` | `$$` 与内容之间不留空格（规则 3） |
| ``$M=1$`` | ``$M = 1$`` | 行内公式用同一套空格规则 |
| ``$y_{i,k}=C_ix_{i,k}+D_i u_{i,k}$`` | ``$y_{i, k} = C_ix_{i, k} + D_iu_{i, k}$`` | ……渲染里连在一起的内容，代码里也连在一起 |
| `$$f(x,y)$$` | `$$f(x, y)$$` | 逗号前不加、后加一个空格 |
| 不是 `\\` 的换行 | 拼回同一行 | 只在 `\\` 处换行（规则 5） |
| `\\` 之后的下一行 | 比首行多一个 tab | 续行 = 首行缩进 + 1 个 tab；`\begin{}` 不额外缩进（规则 4） |

示例 —— 列表项里的矩阵公式：

```
	说明$$T = (a, b){\begin{bmatrix}1 \\
		a & b \\
		\end{bmatrix}}$$
```

不碰的地方：frontmatter、围栏代码块与缩进代码块、行内代码、`\text{…}` / `\operatorname{…}` 参数里的文字与空格、含 `%` 注释的公式、带 `\\` 的行内公式。**落单的 `$$` 不再让整篇失效** —— 配起来不像公式的区域（含空行 / 标题 / 围栏 / 分隔线）自动跳过，后面的真公式照排。

### 8. 空格排版（排版格式）

公式排版管的是 `$…$` **里面**的 LaTeX 代码，这一项管 `$…$` **外面** —— 中文、英文、数字、公式、标点之间该不该空一个字宽，也就是使用者实际看到的格式。

| 排版前 | 排版后 | 规则 |
|--------|--------|------|
| `用anki卡片记笔记` | `用 anki 卡片记笔记` | 中英文之间空一个字宽（行内代码、双链、链接、标签与英文等价） |
| `第 3 章` | `第3章` | 中文和数字之间**不留空格**（笔记规则），已有空格一并删掉 |
| `用GPT4写代码` | `用 GPT4 写代码` | 含字母的连写（`GPT4`、`3D`、`v1.2.2`、`100kg`）整体算一个英文单词，型号不会被拆开 |
| `设$x$为未知数` | `设 $x$ 为未知数` | 行内公式与前后文字之间空一格；`$` 内侧一个字符都不动 |
| `中文 ，内容 。` | `中文，内容。` | 全角标点两侧不留空格 |
| `word,word` | `word, word` | 半角标点 `, . ! ? :` 前不留空格、后空一格（小数点 `1.2.2`、时间 `12:30`、省略号 `...` 除外） |
| `如, ：`、`7. 并列：&` | `如,：`、`7. 并列：&` | 符号与符号之间也贴紧 —— **空格只用来分隔不同语言的内容**，不用来分隔两个符号 |
| `甲 & 乙`、`甲 \| 乙`、`甲 → 乙` | `甲&乙`、`甲\|乙`、`甲→乙` | 符号与中文之间贴紧（已有的空格一并收掉）：`&` 是标点、`\|` `→` 是数学符号，中文与它们之间没有那一格 |
| `A & B`、`$A$ & $B$`、`word, word` | 不变 | 只有中文与**西文单词 / 数字 / 公式**之间才谈那一格空隙（W3C《中文排版需求》：不多于四分之一汉字宽；汉字与标点是 1:1 方块、无缝隙并列） |
| `（ + ）`、`" + "`、`《 书名 》` | `（+）`、`"+"`、`《书名》` | 包裹符号（`（）` `《》` `“”` `""`）**本身不算内容**：内侧永远贴紧，里面的符号只是"被提到"，不朝它要那一格；圈住的文字内部照旧（`《新 吊带袜天使》` 保留） |
| `x ^ 2`、`等等 ... 内容` | `x^2`、`等等...内容` | 修饰符号 `^` 与省略号 `...` 前后不空 |
| `( x )`、`中文 (说明)`、`f (x)` | `(x)`、`中文(说明)`、`f(x)` | 半角括号**前后都没有空格**（英文符号 3），就是函数 `f(x)` 那种写法；英文句子里括号两侧是英文词距，外侧保留 |
| `100kg`（可选，默认关闭） | `100 kg` | 数字与单位之间空一格，单位须落在内置词表里 |
| `元素: $A$` | `元素：$A$` | 中文语境里的半角 `, : ; ! ?` 换全角，**纯英文**行里的 `，。、；！？` 换半角（什么语境用什么标点）。中文方向按**句**判定而不是只看左邻一个字符：左边是中文、右边是中文、或整句以中文为主（公式、代码、链接里的字母不算英文，且用**词数**而不是字母数）就换 —— `没有 $M_{ij}$, 且` → `没有 $M_{ij}$，且`。英文方向只在**整句一个中文字都没有、且至少两个英文单词**时生效，`参数 gain=50、shift=0` 这类半中半英的行不动。`.` 不换（省略号、版本号、`e.g.`），`（）`、`：`、`《》`、数字后面的标点（`1,000`、`12:30`）、反斜杠后面的 `\,`、半角括号里（`(mod, k)`）与 `/` 之间的标点、聊天记录头部 `张三: 2024/…`、书名号引号内部也都不动 |

规则全部来自本插件配套的笔记规范：不同语言之间空一个字宽、与标点之间不空、中文与数字之间不空。**[`docs/规则登记表.md`](docs/规则登记表.md) 是完整的对照表** —— 每条规则都标着它实现规范里的哪一条、由哪个设置开关控制、落在哪个模块、哪个测试在守（四处对不上，`npm test` 就失败）。两条会误伤专有名词的规则默认关闭：英文↔数字（`GPT4`、`3D`、`v1.2.2`）与数字↔单位。符号那一类走中文排版规范（W3C [中文排版需求 clreq](https://www.w3.org/TR/clreq/)）：**空隙只加在汉字与西文字母、数字之间**（§6.3.3，不多于四分之一汉字宽，行首行尾不加），标点旁边连这个空隙都不加，汉字与标点更是 1:1 方块、无缝隙并列（§1.2）；CSS `text-autospace` 的默认值同样只在中西文之间加空隙，标点要显式写 `punctuation` 才加。

不碰的地方：frontmatter、围栏代码块与缩进代码块、`$$ … $$` 公式块（含中间所有行）、**GFM 表格行**（表格里的空格是对齐用的，`|` 是单元格分隔符）、行内代码、双链与 markdown 链接、URL、HTML 标签、`%%注释%%`、`#标签`，以及 `《…》` `〈…〉` `“…”` 内部（《新 吊带袜天使》《a子计划》原样保留）、中文与中文之间的空格、数学运算符（`ctrl+c` 不会被拆）、`|x|` / `P(A|B)` / `x̂_{k|k}` 这类紧贴字母数字的竖线（属于数学记号）、`e.g.` / `i.e.` / `Q&A` / `R&D` 这类单字母缩写里的点与和号。

强调标记不参与规则本身，规则看的是它包住的内容：`**可逆矩阵**$P$` → `**可逆矩阵** $P$`、`中文**English**中文` → `中文 **English** 中文`。空格只加在标记**外面** —— 插进 `**` 与文字之间会让粗体失效（渲染成两个星号）。配不成对的星号（`2*3`、`a*b`）原样留着，不当强调处理。

实测里踩到的三个坑，都已修掉：

- **同一行里带 `$$…$$` 的行照样排版**：`1.矩阵指数$e^{At}$是$$…$$` 以前整行被当成公式跳过，于是这一行一个字符都修不了。现在同一行成对的 `$$…$$` 按"行内公式"整体处理，行内其余文字正常排版；只有**跨行**公式块中间的行才整行跳过，且首行 `$$` 之前、末行 `$$` 之后的正文仍会排。
- **NBSP（U+00A0）算空格**：从 Word / PDF 粘进来的不换行空格看着和空格一样，规则却看不见它（`矩阵\u00A0A` 永远修不到）。现在规则生效的位置一律统一成普通空格，规则管不到的位置原样保留。
- **只有空白的行清成真正的空行**：只装 Tab 或空格的行渲染没区别，但会留下看不见的缩进。

设置面板按"代码格式 / 排版格式"分区，每条规则各有一项开关：
| 设置项 | 默认 | 说明 |
|--------|------|------|
| 中文与英文之间 | 空一个字宽 | 也可选"保持原样" |
| 中文与数字之间 | 不留空格 | 可选"空一个字宽"（盘古之白写法）或"保持原样" |
| 英文与数字之间 | 保持原样 | 可选"空一个字宽"；保持原样可避免拆开 `GPT4` `3D` `v1.2.2` |
| 公式与文字之间 | 空一个字宽 | 也可选"保持原样"；只动 `$` 外面 |
| 标题标记与标题内容之间 | 开 | 按规范「第一章，第一课，附录1 等标题和标题内容之间需要加空格」：`第一章矩阵` → `第一章 矩阵`、`第1课五十音` → `第1课 五十音`、`附录A矩阵` → `附录A 矩阵`。认两种标记：`第` + 序号 + 章 / 课 / 节 / 讲 / 篇，以及 `附录` + 序号（`附录A` `附录1` `附录一`，序号必填）；标记后面跟着标点（`第一章、矩阵`）或没有内容时不动，已经空开的也不动 |
| 全角标点两侧不留空格 | 开 | 引号与书名号内侧除外 |
| 半角标点前不留空格、后空一格 | 开 | 小数点、时间、省略号除外 |
| 符号自己的空格规则 | 开 | **空格只分隔不同语言的内容**：`甲&乙`、`如, ：` → `如,：` 贴紧；`A & B`、`word, word` 留一格；`^` 与 `...` 前后不空；包裹符号内侧贴紧；表格行整行跳过 |
| 括号前后都没有空格 | 开 | `( x )` → `(x)`、`中文 (说明)` → `中文(说明)`、`f (x)` → `f(x)`；英文句里外侧保留 |
| 数字与单位之间空一格 | 关 | 单位须在词表内，`%`、`3D`、`4K`、`5G` 不算 |
| 半角标点转全角 | 开 | 紧跟在中文后面的 `, : ; ! ?` 换全角；`.` 与 `()` 不换；被提到的符号（`如, ：`）不换 |
| 正文数学符号自动加公式 | 开 | `矩阵 A` → `矩阵 $A$`、`n维` → `$n$ 维`、`V(F)` → `$V(F)$`、`x = 0` → `$x = 0$`、`λ` → `$\lambda$`；笔记里已经写好的公式会给全篇同名变量当依据；详见第 9 节 |

### 9. 智能公式：正文里的数学符号自动套公式

正文里按普通文字敲的数学符号会自动包上 `$…$`，渲染成公式，并接着被「公式排版」整理：

| 排版前 | 排版后 | 规则 |
|--------|--------|------|
| `矩阵 A` / `矩阵A` | `矩阵 $A$` | 紧挨中文的单个拉丁字母视为变量 |
| `n维` / `n 阶` / `n 次` | `$n$ 维` / `$n$ 阶` / `$n$ 次` | 量词也算中文锚点 |
| `V(F)` / `a(b)` / `T(x)` | `$V(F)$` / `$a(b)$` / `$T(x)$` | 单字母 + 括号参数 |
| `x = 0` / `x = Tz` / `Ax = λx` | `$x = 0$` / `$x = Tz$` / `$Ax = \lambda x$` | **整段算式**一起包 —— 不能只包字母，否则 `= 0` 会落在公式外面 |
| `x - 1` / `n - 1` / `a + b` | `$x - 1$` / `$n - 1$` / `$a + b$` | **运算符两侧各留一格**才算算式（数学符号 1） |
| `x=0` / `a+b+c` / `5/10mm` / `A-7` / `cd /d` / `x -1` | 原样不动 | 紧贴的一律不认：那可能是作者故意写的编号 / 连字符 / 命令，也可能就是在正文里省了空格 —— 排版不猜。正负号是修饰符号（数学符号 3），`x = -1` 照旧包 |
| `a, b ∈ F` | `$a, b \in F$` | 逗号、数字、运算符都算同一段 |
| `特征值 λ` | `特征值 $\lambda$` | 希腊字母与 `∈ ≤ ≥ × →` 等换成 LaTeX 命令；命令后面紧跟字母时补一个空格（`\lambdax` 是未定义命令） |
| 已写过 `$z$`，后文 `讨论 z 的模长` | `讨论 $z$ 的模长` | **变量表**：你在笔记里把 `z` 标成公式，就等于声明"z 是变量" —— 全篇后面再单写的 `z` 都跟着包，不用再靠语境词猜 |
| 已写过 `$$z = a + bi$$`，后文 `因此 z 的实部` | `因此 $z$ 的实部` | `$$…$$` 区块里的变量一样算数（跨行区块也算） |
| 已写过 `$e^{At}$`，后文 `其中 A 是矩阵，t 是时间` | `其中 $A$ 是矩阵，$t$ 是时间` | 复合公式里的字母同样进变量表；`\sin` `\mathrm` `\text{max}` 这类命令名与"当文字排"的内容不算 |

刻意保守 —— 它改的是正文，所以"拿不准就不动"。只有拿到"这确实是数学"的证据才包：

- 这一段里有括号或运算符（`V(F)`、`x = 0`、`a, b ∈ F`）；
- 左边紧挨数学语境词（`矩阵 A`、`向量 x`、`数域 F`、`特征值 λ` …）；
- 右边紧挨量词（`n维`、`n 阶`、`k 行`）；
- 这一段里有希腊字母（希腊字母在正文里只可能是数学）；
- 前文（或本行前面）已经确认过同名变量 —— `矩阵 A …… 称为 A 的秩` 里的第二个 `A`，以及变量表里的 `z`。

变量表的几条边界：只认**同一篇笔记**里已经写好的公式（`$…$` 与 `$$…$$`，含跨行区块），不跨笔记；代码块、行内代码、frontmatter 里的 `$z$` 不算数；大小写是两个符号（写了 `$z$` 不会让 `Z` 跟着走）；仍然要求紧挨中文或中文标点，所以 `the value z is` 这类英文句子照旧不碰；`Q_inv`、`z^2`、`z_1` 这类带 `_` `^` 的命名约定照旧不碰。包完的公式就是"已有公式"，下一轮排版结果不变。

其余一律不动：frontmatter、围栏/缩进代码块、行内代码、双链与链接、URL、HTML 标签、标签、注释、已有公式（原样保留，只是会被读成变量表）、`《…》` `〈…〉` `“…”` 内部（《a子计划》保持原形）、英文散文、三个字母以上的单词（`Jordan`、`latex`、`Steinitz`）、没有算式的两字母缩写（`AI`、`QQ`、`pg`、`tv`、`xx`）、两字母虚词（`is`、`to`）、缩写（`e.g.`、`i.e.`）、路径与扩展名（`C:\data`、`main.ts`）、运算符两侧没各留一格的写法（`x=0`、`a+b+c`、`5/10mm`、`A-7`、`cd /d`）、带 `_` `^` 的命名约定（`Q_inv`、`x^2`、`a_ij`）、分条标签（`(a)`、`(b)`）、任务复选框（`- [x]`）、字母 + 专有名词后缀（`C 语言`、`D 盘`、`A 股`）。不想要就在设置里关掉。

### 10. 列表序号与标题级别整理

两条"保证式"整理，**默认开启**，只修不齐的地方：

**整理列表序号** —— 保证每个列表的首项编号是 1。首项不是 1 时整段从 1 起逐项 +1；首项已经是 1 的列表一律不动，所以作者特意写的 `1. 1. 1.`（靠 Markdown 自动递增）或 `1. 5. 9.` 都不受影响。空行不断列表（松列表算同一个），段落、代码块、表格会切断列表；嵌套列表各自从 1 开始；编号不加前导零。

| 修复前 | 修复后 | 规则 |
|--------|--------|------|
| `3. 甲` / `4. 乙` | `1. 甲` / `2. 乙` | 首项不是 1 → 整段重排 |
| `2. 父` / `⇥3. 子` / `4. 父二` | `1. 父` / `⇥1. 子` / `2. 父二` | 子列表各自从 1 |
| `1. 甲` / `1. 乙` | 不变 | 首项已是 1 |
| `2. 甲` / 空行 / `正文` / 空行 / `3. 乙` | `1. 甲` / 空行 / `正文` / 空行 / `1. 乙` | 段落切断列表 |

**整理标题级别** —— 保证子标题与父标题恰好差一级：`# 标题` 下面直接写 `#### 子标题` 会压成 `##`，同级标题保持同级，回退时回到正确的父级。**多个标题同时改时，所有级别都从原始级别一次算出**（不拿"上一个标题的新级别"当依据）—— 否则 `# → ### → ###` 会被算成 `# → ## → ###`，把并列的两节变成一节套一节，而且改得越多错得越远。首个标题的级别保持原样（`##` 起头的笔记往往是接着上一层的分级）。frontmatter、代码块、`#标签`、引用里的标题都不动。

| 修复前 | 修复后 | 规则 |
|--------|--------|------|
| `#` / `####` | `#` / `##` | 跳级压平 |
| `#` / `###` / `###` | `#` / `##` / `##` | 同级保持同级 |
| `#` / `###` / `##` | `#` / `##` / `##` | 回退到父级，是兄弟不是父子 |
| `##` / `#####` | `##` / `###` | 首个标题的级别是基准 |

### 11. 复制图片为文件（可粘进文件夹）

Obsidian 里多数「复制图片」的实现复制的是**位图**：QQ、Word、微信 都收得下，但 Windows 资源管理器不吃这一套 —— 往文件夹里粘贴什么都没有（[这就是当初要解决的那个反馈](https://forum-zh.obsidian.md/t/topic/40964)；Image Toolkit 与 Image Context Menus 都是这个表现）。

本插件改为把**文件**放进剪贴板，所以往文件夹里粘贴得到的就是真实的 `图片.png`：

| 粘贴到哪儿 | 得到什么 |
|------------|----------|
| 资源管理器（或任何文件管理器）里的文件夹 | 真正的图片文件（是复制，不是移动） |
| QQ / 微信 / Word | 图片本身（只有一张图时还会一并放一份位图） |
| 文本编辑器 | 什么都没有 —— 纯文本格式是刻意不写的（文本与文件同时存在时，有些程序会粘两遍） |

**一次复制多张**：把包含图片的正文选中，再用菜单 / 命令 —— 菜单上会按张数显示 **复制 3 张图片（Note Tidy）**。图片会去重（同一张图嵌两次只复制一次），同名有歧义的链接跳过而不猜，与本插件其它图片功能一致。

**文字与图片一起**：选区里除了图片还有文字时，文字会跟着一起走 —— 粘到 QQ / 微信 里就是文字与图片按原位排好，而不只是图片。这份复制带一份 HTML 格式（CF_HTML，图片数据内嵌其中）加上纯文本：

| 你选了什么 | 粘到文件夹 | 粘到 QQ / 微信 |
|------------|------------|----------------|
| 只有图片（例如只选 `![[图片.png]]`） | 图片文件 | 图片 |
| 文字 + 图片 | *（什么都没有 —— 这份复制不带文件列表，见下）* | 文字与图片，按顺序排好 |

差别的原因：剪贴板里只要有**文件列表**，QQ 与微信 就会把它当文件直接上传、别的什么都不看 —— 那句文字根本没机会出现（[其它插件踩到的正是这个坑](https://www.wsisp.com/helps/30963.html)）。所以混排那一份只送 HTML + 纯文本，图片以 `data:` URL 内嵌（浏览器内核的聊天客户端不会去加载粘贴进来的 HTML 里的本地 `file:///` 图片）。几条值得知道的后果：

- 要把图片**文件**粘进文件夹，就只选图片（或在某张图片上用「复制图片」菜单项）；
- 图片内嵌上限是单张 8 MB、合计 16 MB —— 更大的图退回 `file:///` 路径，Word 这类程序照样认；
- 图文混排目前只在 Windows 上成立；macOS 上本插件只把文件放进剪贴板（AppleScript 一次只能写一样东西）。

入口（菜单项标题一律带 **（Note Tidy）** —— Obsidian 自带的图片菜单里本来就有一项 *复制图片*，那一项是位图版）：

- **在笔记里右键渲染出来的图片**（阅读视图与实时预览）→ **复制图片（Note Tidy）** 是**追加**进菜单的。什么都不替换：Obsidian 原生项与其它插件的项原封不动；
- **在编辑器里右键、光标落在图片链接上**（或选中了图片）→ 同一项，追加在 Obsidian 自带的编辑器菜单里；
- **命令面板** → **复制图片到剪贴板**（可以给它设个快捷键）；
- **直接按 `Ctrl+C`**（选中图片，或光标落在某张图上）—— 默认关闭，在 **设置 → Note Tidy → 复制 → 「Ctrl+C」优先复制图片** 里打开。规矩同上：只在笔记正文里生效（输入框、设置面板、其它插件的按钮一律放行），选区里的文字会跟着图片一起复制。

**平台**：Windows（PowerShell 一次写入文件列表，单张图时连同位图一起写）与 macOS（`osascript` + `POSIX file`，Finder 里能粘出文件）。Linux 暂时不支持 —— 命令会明确提示，而不是静默失败。

### 12. 状态栏显示选中内容的图片张数

**默认关闭**。打开后（**设置 → 状态栏 → 显示选中内容的图片数量**），在编辑器里选中文字时，右下角状态栏会显示这段选区里有几张图片：`🖼 选中 3 张图片`。只统计**嵌入的图片**（`![[图片.png]]`、`![说明](图片.png)`，带尺寸 / 别名 / `#片段` 的也算，扩展名含 `avif` / `svg`）；指向图片文件的普通链接不算，围栏代码块与行内代码里的链接也不算。没有选中内容、或选区里没有图片时，那一格是空的。

### 13. 管理右键菜单

本插件是往现成的菜单里**插项**（而不是自己弹一份接管），所以它顺带把三个菜单变成"可看、可开关"的：

| 菜单 | 是什么 | 本插件往里加 |
|------|--------|--------------|
| 图片 | 在笔记里右键渲染出来的图片 | 复制图片 · 快速设置图片大小 · 快速修复聊天记录 · 管理右键菜单 |
| 笔记 | 右键笔记正文 | 复制图片 · 快速设置图片大小 · 快速修复聊天记录 · 管理右键菜单 |
| 文件夹 | 在文件浏览器里右键文件或文件夹 | 管理右键菜单（原有的「图片功能」/「文本排版」二级栏本来就在） |

- 先在你要管的那个菜单里右键一次，再点里面的 **管理右键菜单…（Note Tidy）**（或从命令面板运行 **管理右键菜单**）→ 面板会列出那个菜单里当时有什么 —— Obsidian 原生项、其它插件的项与本插件的项；
- **开关开着就表示这一项会显示**；关掉它，这一项就从菜单里藏起来。本插件自己的项由各自的开关控制，绝不会被这份名单藏掉；
- 全部存在 **设置 → Note Tidy → 右键菜单** 里，那份名单也可以直接当纯文本编辑（`图片：标题` / `笔记：标题` / `文件夹：标题`），清空「隐藏的菜单项」一栏等于全部恢复显示。

设置项（**设置 → 右键菜单**）：

| 设置项 | 默认 | 说明 |
|--------|------|------|
| 「复制图片」菜单项 | 开 | 在图片菜单与笔记菜单里插入「复制图片（Note Tidy）」（什么都不替换） |
| 「快速设置图片大小」菜单项 | 开 | 插入「快速设置图片大小（Note Tidy）」—— 用默认尺寸直接改写当前笔记，不弹窗 |
| 「快速修复聊天记录」菜单项 | 开 | 插入「快速修复聊天记录（Note Tidy）」—— 转换本笔记的外部图片并修一遍排版 |
| 「排版选中内容」菜单项 | 开 | 选中一段内容后右键，插入「排版选中内容（Note Tidy）」—— 只排版这段内容（含选区里引用的外部图片转换），笔记其余部分一个字符都不动 |
| 「管理右键菜单」菜单项 | 开 | 插入打开管理面板的那一项（关掉后仍可从命令面板运行） |
| 「图片功能」/「文本排版」二级栏 | 开 | 文件 / 文件夹右键菜单里的两个二级栏（原有功能） |
| 隐藏的菜单项 | 空 | 每行一项 `菜单：标题`，菜单可写 `图片` / `笔记` / `文件夹`（不写按 `图片` 算）；列在这里的项不出现在对应菜单里。这份名单管的是 Obsidian 原生项与其它插件的项 —— 本插件自己的项由上面的开关管，绝不会把自己藏掉；管理面板会替你填这一栏 |

## 使用方式

右键菜单收进了两个二级栏，顶层不再一长串：**图片功能** 与 **文本排版**。两项右侧带 `›` 箭头，悬停或点击即在旁边展开 —— 用的是 Obsidian 原生子菜单，父菜单不会收起，键盘左右键也能进出子菜单。

| 方式 | 操作 |
|------|------|
| 右键 `.md` 文件 | **图片功能**：转换 / 重命名 / 整理位置 / 设置大小 · **文本排版**：修复排版（空格 / 缩进 / 聊天记录 / 标签 / 公式）、快速修复聊天记录（转换外部图片 + 修复排版） |
| 右键笔记 / 文件夹 | 「图片功能」二级栏：转换外部图片、重命名乱码图片、按预设重命名、整理图片位置、**整理图片**（转换格式 + 合并重复副本 + 清理没人引用的附件，先弹确认框）、设置图片大小；「文本排版」二级栏：修复排版、快速修复聊天记录 |
| 右键文件夹 | 同样两个二级栏，作用于该文件夹下所有笔记（**整理图片**本来就是全库范围，与点的是哪个文件无关） |
| 右键笔记正文 / 笔记里的图片 | 追加「复制图片（Note Tidy）」「快速设置图片大小（Note Tidy）」「快速修复聊天记录（Note Tidy）」「排版选中内容（Note Tidy）」（选中一段内容后才出现）「管理右键菜单…（Note Tidy）」；原生项与其它插件加的项一个都不动。先选中一段含图片的正文再复制时，菜单上会按张数写成「复制 3 张图片（Note Tidy）」 |
| 命令面板 (`Ctrl+P`) | 菜单里的每个操作都有对应命令：转换图片（当前笔记 / 整个仓库）、**把整个仓库的图片转换为指定格式**、**把当前笔记的图片转换为指定格式**、**整理图片（转换格式 + 合并重复副本 + 清理没人引用的附件）**（另一个入口是左侧栏那个一键整理的图标）、**清理没人引用的图片**（先弹确认框）、重命名乱码图片（当前笔记 / 整个仓库）、重命名全部图片（普通 / 强制）、整理图片位置（当前笔记 / 整个仓库）、设置图片大小（当前笔记 / 整个仓库）、复制图片到剪贴板、修复排版（空格、缩进、聊天记录、标签与公式，当前笔记 / 整个仓库）、快速修复聊天记录（转换外部图片 + 修复排版）、管理右键菜单 |

设置面板按规范里的分区排列：**图片导入**、**图片大小**（图片），**代码格式**（LaTeX 源码怎么写），**排版格式**（读者实际看到的格式），另有 **状态栏**（选中的图片张数）、**右键菜单**（各菜单项的开关与隐藏名单）、**复制**（编辑器里的 `Ctrl+C`）三节。

**图片导入**这一节里与格式转换有关的两项：

- **导入的图片转成目标格式**（默认开）—— 把收进仓库的外部图片转成目标格式（`png`/`jpg` → `webp`），链接直接写成转换后的文件名。转码用插件自带的编码器，不依赖别的插件；解不开的格式与转完更大的图片按原格式导入。
- **「转换图片格式」的目标格式**（默认 **webp**）—— 上面那条全库命令转成什么，以及「整理图片」转换那一步转成什么：`webp` / `jpg` / `png` 三选一。动图 `gif` 与已经是目标格式的图片一律跳过。
- **转换质量**（默认 **75**）—— JPEG / WEBP 用它决定压缩程度（PNG 无损，忽略这一项）。
- **粘贴图片由本插件接管**（默认开）—— 粘图片文件时由本插件一张一张存盘 + 转格式 + 写链接；**建议同时把 Image Converter 的「Never process filenames」填 `*`**，免得两边各存一份。
- **整理时转换图片格式**（默认开）—— 执行「整理图片」时把还不是目标格式的图片转成目标格式；排在合并重复副本之后（马上要进回收站的副本不必白转一趟）。
- **左侧栏放一个「整理图片」图标**（默认开）—— 点一下就是**一键整理**：转换格式 + 合并重复副本 + 清理没人引用的附件，不弹确认框。命令面板与右键菜单里的同名入口仍会先让你确认。
- **整理时清理没人引用的附件**（默认开）—— 整理时顺手清一遍"没人引用的图片"：扫描全库笔记与 canvas 里的引用，一张都没被提到的送进回收站（只清图片，pdf、音频等一个都不碰）。自己实现，不依赖 Clear Unused Images。

## 支持的图片格式

`png` `jpg` `jpeg` `gif` `bmp` `webp` `heic`（图片大小功能额外支持 `avif` `svg`）

## 图片大小设置项

| 设置项 | 说明 |
|--------|------|
| 默认宽度 | 弹窗打开时的默认宽度（像素），与高度都留空表示移除已有尺寸 |
| 默认高度 | 可留空，此时按宽度等比例缩放 |
| 覆盖已有尺寸 | 关闭后只给还没有尺寸的图片补上 |
| 粘贴图片时自动套用默认尺寸 | 默认开启。刚粘进笔记的图片按上面的默认宽度 / 高度加上尺寸（与「快速设置图片大小」同一套参数），只改刚粘的那一段，详见第 4 节 |

## 注意事项

**重命名图片后请勿使用 Ctrl+Z 撤销。** 插件会修改磁盘上的物理文件名，编辑器的撤销只能回退文本中的链接文字，无法还原文件名，会导致图片无法显示。

批量操作前建议备份仓库。

- 修复：整库批处理遇到**第一篇读不出来的笔记就中断**，后面所有笔记被静默跳过 —— 表现为"整库没修、单篇能修"。现在单篇失败记日志、计入失败数、继续跑完，结果提示里说明处理了多少篇、几篇出错
- 修复：整库写盘改用 `vault.process`（原子读—改—写），不再把编辑器里尚未落盘的改动覆盖掉
- 修复：行首缩进修复不再把 `#标签` 当成标题，标签行前手滑多打的空格会被删掉
- 新增：块级标记的空白规范 —— 多级引用（`">>引用"` → `"> > 引用"`）、callout（`">[!note]"` → `"> [!note]"`）、列表符号后的多个空格（`"-    项目"` → `"- 项目"`）、标题符号后的多个空格（`"##   标题"` → `"## 标题"`）。`#标签` 后面没有空格，是标签不是标题，不会被加空格；列表项里的引用、引用里的嵌套块，缩进有语法含义，一律保留
- 新增：**标签排版** —— 一块内容里同时有正文和标签时，标签统一挪到块尾并与正文空一格。一个段落算一块，一行列表项、一行标题各自算一块，**表格按单元格算块**（整行算一块会把标签挪到别的列）；整行只有标签时位置不动。frontmatter、围栏代码块、缩进代码块、`$$` 公式、行内代码、`%%注释%%`、双链与 Markdown 链接里的 `#` 都不算标签
- 新增：**标签排序** —— 同一处出现的多个标签按首字母排序（中文按拼音、数字按数值）
- 新增：**内容板块排版** —— 按首字母对笔记各块内容排序。标题把笔记切成小节、只在小节内排序；表格、图片、分隔线、脚注、公式、聊天记录是锚点，原地不动并切开排序范围；列表与段落分别排序、互不穿插；有序列表排完顺手把编号写顺
- 新增：**公式排版** —— 整理数学公式的 LaTeX 代码（`$$…$$` 区块与行内 `$…$`，行内只按空格规则、不换行），让代码里的空格与公式渲染出来的空格一致：`=` `+` `\le` `&` `\\` 左右各一个空格；一元正负号与 `\partial` `\delta` `\sin` 这类命令和参数贴紧（`\delta x` → `\delta{x}`）；逗号前不加、后加一个空格；`$$` 与内容贴紧；多余空格与不是 `\\` 的换行全部删掉；只在 `\\` 处换行，续行缩进 = 首行缩进 + 1 个 tab。间距命令与后面字母粘连（`\quadA`，LaTeX 会当成未定义命令报错）会拆开：前面已有逗号等分隔就删掉多余的间距，否则写成 `\quad{A}`。`\text{…}` 里的文字、代码块、带 `\\` 的行内公式都不动
- 结果提示现在会写明**本次处理多少篇、几篇出错、开了哪几步** —— "为什么这篇没修"（某一项开关没开）一眼可见
- 命令回调改为返回 Promise，整库批处理路径可以被测试直接驱动
- 新增模块 `src/markdown-markers.ts`、`src/tags.ts`、`src/block-sort.ts`、`src/latex-layout.ts`、`src/text-pipeline.ts`、`src/line-scan.ts`、`src/collate.ts`，以及对应的期望输出、安全边界与幂等性测试；`test/commands.test.ts` 增加整库批处理的回归测试（含"中间一篇读取失败"的用例）
